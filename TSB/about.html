Bureau Notes

A filing guide for an expanding archive of impossible places.

bureau memo: TSB-ABOUT // revision: 2.1 // circulation: PUBLIC EXTRACT
The Threshold Survey Bureau is a fictional wrapper for an independent archive of original Backrooms environments. The casework is invented. The spaces are built to feel as though somebody returned from them with evidence.

Purpose

The Threshold Survey Bureau is a fan-made website for original Backrooms levels created as environments, Blender scenes and Unity game maps. Each environment receives a dedicated field dossier so the archive can grow gradually as new projects are completed.

Design Approach

The interface is styled as a collection of analog investigation records: aged documents, manila filing surfaces, stamped notices, taped field photographs and typewritten labels. Its structure remains intentionally practical, with a persistent index, local search, reusable reports and print-friendly article pages.

Adaptive environment themesThe Bureau shell remains consistent across the archive, but each dossier can inherit its own environmental palette. This lets every level feel distinct without losing the readable wiki-like filing system.

Filing Another Environment

  1. Duplicate the blank field report.
  2. Move the copied file into the levels folder.
  3. Replace the placeholder title, classification, sections and document metadata.
  4. Add the new dossier to levels/index.html.
  5. Add its searchable title and keywords to assets/js/search-data.js.
  6. Add its URL to the random-dossier list inside assets/js/site.js.
