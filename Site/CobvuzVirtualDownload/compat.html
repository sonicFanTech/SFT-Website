GUEST OS SUPPORT

Windows 1.0 to 10.
And Linux.

Every OS below is supported. Firmware is auto-suggested in the wizard — you can always override it.

Windows 11 not supported as a guest

Windows 11 requires TPM 2.0. While Hyper-V Gen 2 VMs can emulate a virtual TPM, full Windows 11 guest support requires additional configuration beyond Cobvuz Virtual's current scope. Windows 10 is the recommended modern Windows guest.
