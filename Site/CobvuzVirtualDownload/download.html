System Requirements

Windows 10/11 Pro, Enterprise, or Education
CPU
Intel VT-x or AMD-V enabled in BIOS/UEFI
RAM
8 GB host RAM recommended
Architecture
64-bit (x64) only
Hyper-V
Must be enabled — comes free with Windows Pro
Privileges
Must run as Administrator

Setup Steps (after release)

1
Enable Hyper-V
Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Hyper-V -All
2
Get firmware files
Copy bios.bin → seabios.bin and edk2-x86_64-code.fd → OVMF.fd from a QEMU install into firmware\
3
Create a virtual switch
Open Hyper-V Manager → Virtual Switch Manager → New External switch for internet access
4
Run as Administrator
Right-click CobvuzVirtual.exe → Run as administrator (required for Hyper-V WMI)
✓
You're ready!
Click + New VM in the toolbar and follow the 6-step wizard
