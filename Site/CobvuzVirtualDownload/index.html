WHAT'S INSIDE

Built different.
No compromises.

⚡

Hyper-V WMI Engine

Talks directly to Hyper-V through root\virtualization\v2 WMI. No QEMU. No KVM. Uses your Windows built-in hypervisor for maximum performance.

Requires Windows 10/11 Pro · Run as Admin
🧬

Dual Firmware

Choose per-VM at creation. SeaBIOS for DOS, Windows 9x and XP. OVMF (UEFI) for Windows 7 through 10 and modern Linux.

SeaBIOS OVMF Secure Boot
🖥️

Native Win32 GUI

Zero Qt. Zero MFC. Zero Electron. Pure Win32 + GDI with a custom dark theme, DPI-aware rendering, and dark title bar via DWM.

C++17 · MSVC 2022 · x64
📦

3 Custom DLLs

Clean modular architecture. Each DLL handles one job:

HyperVBridge.dll — WMI / VM lifecycle
FirmwareManager.dll — BIOS / UEFI
VMStorage.dll — configs & disks
🧙

6-Step VM Wizard

Name & OS → Hardware → Storage → Network → Firmware → Summary. Auto-suggests the right firmware for the OS you pick. No manual config needed.

🗂️

Full VM Control

Start · Stop · Pause · Resume · Save state · Delete — all from one window. Background threads keep the UI responsive. VM state syncs live from Hyper-V.

GUEST OS SUPPORT

Windows 1.0 to Windows 10.
And Linux.

Every OS below has been tested or is directly supported by Hyper-V with the correct firmware.

🪟

Modern Windows

UEFI (OVMF)
Windows 10 (32 & 64-bit) ✓ Best experience
Windows 8 / 8.1 ✓ Works great
Windows 7 (32 & 64-bit) ✓ UEFI or Legacy
Windows Vista ✓ Legacy recommended
💾

Classic Windows

Legacy (SeaBIOS)
Windows XP (32-bit) ✓ Works well
Windows 2000 / ME ✓ Low RAM (128–256 MB)
Windows 98 / 95 ✓ 16–128 MB RAM
Windows 3.x / 1.0 ✓ Historical — 4–16 MB
🐧

Linux

UEFI or Legacy
Ubuntu / Debian ✓ Both firmware work
Fedora / RHEL / CentOS ✓ Both firmware work
Arch Linux ✓ UEFI recommended
Other Linux distros ✓ Distro dependent
📟

DOS & Notes

Legacy (SeaBIOS)
MS-DOS / FreeDOS ✓ 16–32 MB RAM
Windows 11 requires TPM 2.0 and is not currently supported as a guest OS.
