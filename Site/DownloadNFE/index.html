Noxen File Explorer: Razer Native

v2.0 R1 is the first full native C++ release of Noxen File Explorer. It rebuilds the older Python/PySide6 version into a faster, cleaner, more expandable Windows file explorer with a real native desktop application structure.

This site is the main download and information center for NFE. It includes direct download pages, build history, features, setup guidance, licensing information, and release notes in a 1998-style desktop layout.

What makes v2.0 R1 important?

Full native rebuild

NFE is no longer just a Python application packed into an EXE. The new build is a native C++ / Qt desktop app designed for better stability, improved folder browsing responsiveness, and cleaner long-term maintenance.

Real file explorer workflow

The new release brings back tabs, Home / Quick Access, This PC, custom drive tiles, view modes, preview/details pane, keyboard shortcuts, and better session handling.

Built-in MTP support

Phones and other Windows portable devices can now be browsed directly inside the main program instead of relying on a second companion tool.

Bundled archive tools

Archive and ISO support is built in through modular feature DLLs and bundled 7-Zip runtime files, so users do not need to install 7-Zip separately just to use NFE archive features.
