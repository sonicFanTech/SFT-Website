What is Noxen File Explorer?

Noxen File Explorer is a custom Windows file manager with tabbed browsing, Home / Quick Access, This PC, drive tiles, preview/details areas, archive tooling, and MTP device browsing. The Razer Native line is a rebuild of the older Python/PySide6 app into a native C++ / Qt desktop application.

Explorer-style navigation

Tabs, address/navigation controls, search area, Back/Forward/Up, Backspace-as-Up, and a familiar folder browsing workflow.

This PC + MTP

Custom This PC page with local drives, removable drives, and portable device support through native helper DLLs.

Archive and ISO support

Feature DLLs handle archives, ISO tasks, shortcuts, and bundled 7-Zip files without relying on your system 7-Zip install.

Updater foundation

NFEUpdate.exe handles package preview, update, repair, rollback storage, history, logs, cache cleanup, and checksum validation.

Important notes
Normal build is recommended. It has the cleanest layout for update testing, repair, and troubleshooting.
One-file build: useful for portable/single-EXE style use, but it still extracts an internal runtime at launch because Qt plugins and helper files must exist on disk.
Updater packages: update ZIP/7z/TAR/WIM files are not the same as user-facing GitHub release ZIPs. They are used by NFEUpdate.exe.
