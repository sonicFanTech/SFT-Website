Feature overview

What v2.0 R1 includes

Noxen File Explorer: Razer Native is not just a small update. It is a large rebuild of the original NFE concept with a native architecture, modular DLL features, and a much more complete desktop file explorer workflow.

1. Native Foundation
  • Full native C++ / Qt rebuild of the older Python/PySide6 version.
  • Visual Studio / MSVC project structure rather than a script-packed EXE approach.
  • Cleaner runtime packaging with a standard build and an optional one-file EXE build.
  • Closed-source freeware release model with in-app license access.
2. Browsing, Tabs, and Home

Tabbed browsing

Open multiple locations in one window, duplicate tabs, close other tabs, and restore the previous tab session between launches.

Address bar

Enter direct paths, navigate with Back / Forward / Up / Refresh, jump to This PC or Home tokens, and run command-style entries from the address box.

Home / Quick Access

Home page includes common folders, pinned folders, recent locations, recent files, and cleanup tools for clearing or removing Quick Access items.

Preview pane

Preview/details pane support is built in and can be toggled from the View menu and settings.

3. This PC and Drive Features
  • Custom This PC page for local drives, removable drives, network locations, and supported portable devices.
  • Storage usage bars with adjustable colors for used space, free space, almost-full state, and full/critical state.
  • Drive context actions such as open, open in new tab, eject where supported, and open Disk Management.
  • Settings support for drive display behavior and start-page selection.
4. Built-In MTP Support

One of the biggest improvements in the C++ release line is that MTP phone support is now built directly into the main program.

  • MTP device scanning happens on startup, manual rescan, and device connect/disconnect events.
  • Device browsing is built into the main window rather than requiring a separate companion browser.
  • Dedicated feature DLLs handle MTP scanning, MTP filesystem browsing, and MTP actions.
  • Exporting files from phone to PC and sending files from PC to the current MTP location are supported.
5. Archives, ISO Files, and 7-Zip Integration
  • Bundled 7-Zip runtime files, so users do not need to install 7-Zip separately for NFE archive features.
  • Archive actions include extract here, extract to folder, extract to chosen folder, test archive, create ZIP, and create 7Z archives.
  • ISO actions include mount and dismount support.
  • 7-Zip File Manager can be launched from NFE for users who want the real 7-Zip archive viewer/manager experience.
  • Shortcut tools include create shortcut here, open shortcut target, and open target location.
6. Final Polish, Controls, and Help
  • View modes: Details, List, Small, Medium, Large, and Extra Large icons.
  • Ctrl + mouse wheel icon zoom in supported views.
  • Keyboard shortcuts such as F2 for rename, Delete to Recycle Bin, and Ctrl + L for address-bar focus.
  • About window with clickable GitHub and website links.
  • Help menu entries for GitHub page, NFE website, NFE license, and 7-Zip license.
