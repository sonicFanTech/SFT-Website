Changelog for v2.0 R1

Development summary

This page summarizes the main milestones that formed the final public RNR1 build.

StageMain focusKey outcomes
Phase 1Native project foundationCreated the Visual Studio / MSVC native project and restored basic folder browsing, sidebar, and main window structure.
Phase 2This PC and drivesAdded drive tiles, storage bars, drive actions, and This PC workflow.
Phase 3Home / Quick AccessAdded Home page, pinned folders, recent locations, and saved settings foundation.
Phase 4Preview pane and drive bar customizationAdded preview/details pane, better startup logic, and custom drive-bar colors.
Phase 5About and app identityAdded the app icon, About window, and remove actions for pinned/recent items.
Phase 6Quick Access cleanup toolsAdded remove-all and clear-all actions for pinned and recent data.
Phase 7Built-in MTP supportAdded device scanning, MTP browsing, action support, and the final stable phone-browsing workflow.
Phase 8Archive / ISO / shortcut toolsAdded bundled 7-Zip support, archive extraction/creation, ISO tools, shortcut actions, and license windows.
Phase 9View modes and polishAdded Explorer-style view modes, saved icon sizes, keyboard shortcuts, and tab menu polish.
Phase 10MTP action polishAdded export/send operations, rename support where possible, and toolbar improvements for MTP folders.
Final cleanupRelease identity and packagingAdded final branding, clickable links, one-file EXE build, and packaging fixes.
