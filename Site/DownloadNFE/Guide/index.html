Quick start

First-time use guide for NFE v2.0 R1

This guide walks through the normal first-use workflow for the current NFE release line.

1. Download and prepare the build
  1. Open the Latest Build page.
  2. Choose the normal build or the one-file EXE build.
  3. Download the ZIP file and extract it into a clean folder.
  4. If you are using the normal build, keep the EXE and the Resources folder together.
  5. If you are using the one-file build, you only need the one EXE from the extracted ZIP.
2. First launch behavior

On first launch, NFE opens into its native window layout with the menu bar, toolbar, address bar, sidebar, main content view, and preview/details pane. Depending on the saved settings or start page behavior, you may begin on the Home page or the This PC page.

If you are using the one-file EXE, it will first unpack its private runtime to the user profile before the actual NFE runtime starts.

3. Basic navigation workflow
  • Use the sidebar for Home, This PC, Home Folder, Desktop, Documents, Downloads, Pictures, Music, and Videos.
  • Use the address bar to type a full path directly.
  • Use Ctrl + L to focus the address bar quickly.
  • Use Back, Forward, Up, and Refresh from the toolbar.
  • Use tabs for multiple locations and right-click tabs for duplicate/close actions.
  • Use the View menu for Details/List/Icon modes and icon-size behavior.
4. Connecting and using a phone or other MTP device
  1. Connect the phone to the PC using a USB cable.
  2. Unlock the phone.
  3. If Android asks what kind of USB connection to use, choose file transfer.
  4. Open This PC inside NFE and click Rescan Devices if needed.
  5. When the device appears, open it like any other location.
  6. Use the export/send actions to move data between the phone and the PC.
Important: MTP support depends on Windows, the phone, and the cable. If a device does not show up immediately, unlocking the device and rescanning normally fixes it.
5. Working with archives, ISO files, and shortcuts
  • Right-click a supported archive to extract here, extract to a folder, extract to a chosen location, or test the archive.
  • Select files/folders and create ZIP or 7Z archives directly from the context menu.
  • Right-click an ISO file to mount or dismount it.
  • Right-click an archive and choose the 7-Zip File Manager action if you want the real 7-Zip archive viewer.
  • Use shortcut actions for .lnk files or to create a shortcut in the current location.
