Frequently Asked Questions

FAQ

This page answers the common questions most likely to come up when downloading or using NFE v2.0 R1.

What is the one-file build?

The one-file build is a single EXE edition of NFE. It embeds the runtime payload internally and then extracts the needed runtime files into the user's profile at launch. The app still needs real files on disk behind the scenes because Qt plugins and helper components cannot reliably run straight from memory alone.

Why is MTP different from a normal USB drive?

MTP devices do not expose a normal drive letter filesystem in the same way that HDDs, SSDs, and removable USB drives do. They are portable devices that usually require Windows portable-device APIs and device communication layers. That is why NFE has dedicated built-in MTP support.

Do I need to install 7-Zip separately?

No. The current NFE release bundles the required 7-Zip runtime files so archive tools work out of the box. The program also includes 7-Zip File Manager integration and keeps the 7-Zip license available with the release.

Is NFE open source?

No. Noxen File Explorer is released as closed-source freeware. The program is free to download and use, and it is intended to stay free, but the source code itself is not open source.

More quick answers
  • Can I use the normal build portably? Yes. As long as the EXE and its required resources stay together, the normal build can be used as an extracted portable folder.
  • Can I browse archives directly? NFE supports archive actions directly, and it can also open 7-Zip File Manager for a fuller archive-management workflow.
  • Does NFE replace Windows Explorer? Not in this v2.0 R1 release line. It is a standalone file explorer application.
  • Where do I find the licenses? Use the Licenses page on this site or the Help menu inside the application.
