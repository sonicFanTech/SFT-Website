How this page works

This page lists public NFE releases and also supports parameter-based filtering.

Examples:

  • BuildHistory/?version=v2.0&release=R1
  • BuildHistory/?tag=RNR1

This gives you the dynamic-style build loading behavior you wanted without needing a separate physical page for every release combination.

Quick filters
  • v2.0 R1
  • Tag RNR1
  • Show all listed builds
