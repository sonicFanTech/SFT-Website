Noxen File Explorer: Razer Native

Noxen File Explorer is a Windows file explorer project focused on combining a custom desktop file-management experience with a strong feature set, modular expansion, and a more classic desktop-app feel.

Why the “Razer Native” release exists

The older Python/PySide6 version of NFE already proved the layout and feature idea, but it could become laggy, buggy, and unstable on newer Windows systems. The v2.0 R1 line exists to rebuild that idea as a stronger native Windows application while preserving the NFE identity and workflow.
