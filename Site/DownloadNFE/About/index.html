About NFE

Noxen File Explorer is a custom Windows file explorer project built by sonicFanTech.

Project background

NFE began as a Python/PySide6 file explorer project and later moved into the Razer Native C++ rebuild. The native rebuild keeps the original goals: a custom Explorer-like interface, tabs, This PC, Quick Access, better file management workflow, modular helper tools, and a custom visual identity.

Current direction

The current v2.0.1 R1.1 direction is focused on making NFE easier to maintain and update. The updater foundation, SaveData folder, built-in themes, and fallback repair mode make future NFE updates safer and easier to test.
