Licensing overview

Licenses included with NFE

Noxen File Explorer v2.0 R1 includes two main license areas: the NFE license itself and the 7-Zip license information for bundled archive support components.

Noxen File Explorer license

NFE is distributed as closed-source freeware.

  • The program is free to download and use.
  • The program is intended to stay free.
  • The source code is not open source.
  • Official builds should remain credited to the original project and creator.
  • Redistribution and use should follow the included NFE license text shipped with the release.
7-Zip license

The release bundles 7-Zip components so users can access archive features without installing 7-Zip separately.

  • 7-Zip runtime files are included with the release.
  • The 7-Zip license text is included with the program and should remain available in redistributed builds that include 7-Zip files.
  • 7-Zip File Manager integration is provided for archive viewing and management.
Where to find licenses inside the application

Within NFE itself, you can open the license text directly from the Help menu:

  • Help > NFE License
  • Help > 7-Zip License

This makes it easy for users to review license information without hunting through the runtime folders.
