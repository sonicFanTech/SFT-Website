System requirements and target environment
  • Platform: Windows x64
  • Framework target: Qt 6 / native Windows APIs
  • Main release focus: modern Windows systems with desktop file browsing, removable storage, and optional MTP device access
  • Archive features: rely on bundled 7-Zip runtime files included with the release
MTP device support notes

MTP support depends on Windows portable-device behavior and on the connected device itself. If a phone does not show up right away, try the following:

  1. Unlock the device.
  2. Choose the file transfer USB mode if prompted.
  3. Reconnect the cable if needed.
  4. Open This PC inside NFE and use the Rescan Devices action.
One-file EXE build notes

The one-file build is intended as a convenience distribution. Even though the user only launches one EXE, the application still extracts its runtime to the user profile because that is the practical way to support Qt plugins, helper tools, and external DLL-based features.
