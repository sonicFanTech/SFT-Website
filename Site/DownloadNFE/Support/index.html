Support & Requirements

System requirements, runtime notes, and troubleshooting guidance.

Requirements
Operating system
Windows x64
Runtime
Bundled Qt 6.10.2 files under resources/Qt/
CPU
Modern x64 CPU
Permissions
Normal user mode unless a file operation itself requires elevation
Internet
Only needed for update checks/downloads
Troubleshooting
  • If NFE does not start, run it from the extracted folder and check whether Windows blocked the EXE.
  • If the updater fails, open resources/update/Logs/.
  • If Qt files are missing or broken, use updater Repair so it can relaunch into the Win32 fallback.
  • If one-file build testing seems stale, delete the old extracted runtime cache and run the EXE again.
