SAD-B-D-M-T changelog.

This page records product changes by version so users and technicians can understand which capabilities are present in the build they are using.

v0.1.0 Prototype

Private testing

Initial working prototype • June 2026

Added

  • Modern Windows desktop interface with a branded startup splash screen and sidebar navigation.
  • ADB executable detection with a manual selection option.
  • Connected-device detection and USB-debugging authorization status.
  • Dashboard information for the device model, Android version, firmware build, battery summary, temperature value when reported, and storage usage.
  • Readable TXT diagnostic report export with SAD-B-D-M-T identification, version metadata, report ID, privacy status, issue description, and a data-collection manifest.
  • Complete ZIP diagnostic package export on Windows with the readable report and separate read-only capture files.
  • Common-folder backup for DCIM, Pictures, Download, Documents, and Movies.
  • Live Logcat capture with visible-line filtering, clear, stop, and export actions.
  • Safe restart actions for normal Android restart, recovery mode, and bootloader mode.
  • Read-only third-party application package listing.
  • Advanced terminal page for manual ADB arguments.

Safety boundaries

  • No firmware flashing.
  • No bootloader unlocking.
  • No root workflow.
  • No automated factory-reset button.
  • No system-app removal workflow.
