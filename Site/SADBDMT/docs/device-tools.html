Device tools

Understand normal restart, recovery mode, and bootloader mode before using the clearly labeled device actions.

Read the requested mode before clicking a restart button. Recovery and bootloader modes are different from a normal Android restart.

Available restart actions

ActionWhat it requestsUse it when
Restart Android normallyA standard reboot back into Android.You need to restart the phone after a temporary connection or stability issue.
Restart into recovery modeA reboot request to the device recovery environment.A trusted troubleshooting guide or technician specifically needs recovery mode.
Restart into bootloader modeA reboot request to the bootloader interface.A trusted troubleshooting guide or technician specifically needs bootloader mode.

What the prototype intentionally does not automate

  • Factory reset
  • Firmware flashing
  • Bootloader unlock
  • Root operations
  • Partition modification

Before using recovery or bootloader mode

  1. Confirm that the connected device is the intended phone.
  2. Preserve important files first when the device remains usable.
  3. Know how to return to Android on that device model.
  4. Do not select unfamiliar options in a recovery or bootloader interface.
