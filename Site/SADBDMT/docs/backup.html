Backup

Copy common shared-storage folders to the Windows PC before reset, repair, or deeper troubleshooting steps.

A folder backup is not a complete phone image, cloud backup, or replacement for manufacturer backup software. Confirm that critical information exists in a second safe location before resetting or repairing a device.

Folders available in v0.1.0 Prototype

  • DCIM — camera photos and videos stored in the standard camera folder.
  • Pictures — images stored by apps or copied manually.
  • Download — downloaded files.
  • Documents — documents stored in the common shared-storage folder.
  • Movies — videos stored in the common movies folder.

Run a backup

  1. Connect and authorize the device.
  2. Open the Backup page.
  3. Select the common folders you want to copy.
  4. Choose a destination folder on the Windows PC.
  5. Start the backup and allow the copy process to finish.
  6. Open the destination and verify that the expected files are present.

Important limitations

  • Some apps store data outside shared storage or protect data from normal ADB access.
  • A shared-folder copy does not include every app database, account, message, or device setting.
  • Files that are actively changing or damaged may not copy successfully.
  • An unstable phone may disconnect during the transfer; retry smaller folder groups when necessary.
