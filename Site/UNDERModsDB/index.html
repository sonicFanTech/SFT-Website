* Overview

What It Does

This mod is the UNDERTALE/classic GameMaker port of sonicFanTech's DELTARUNE Debug Menu project. It keeps the usable debug systems while removing the GMS2-only features that do not fit UNDERTALE.

Version: v1.2 Script: SFT_UTDM_Port_v1_2.csx Tool: UndertaleModTool
DOWNLOAD MOD INSTALL GUIDE

* Included

Highlights

  • Classic UNDERTALE-compatible debug menu behavior.
  • Built from the DELTARUNE Debug Menu project as a port.
  • GMS2-only features removed for classic engine limits.
  • Distributed as a UMT .csx patch script.

* Quick Install

Patch Steps

  1. Back up your UNDERTALE data.win.
  2. Open the game file in UndertaleModTool.
  3. Run SFT_UTDM_Port_v1_2.csx from the scripts menu.
  4. Save the patched output.
  5. Launch the game and open the debug menu with F3.

* How to install

INSTALL

  1. Back up your UNDERTALE data.win before changing anything.
  2. Open UNDERTALE's data.win in UndertaleModTool.
  3. Run SFT_UTDM_Port_v1_2.csx from the scripts menu.
  4. Save the patched copy and keep your clean backup somewhere safe.
  5. Start UNDERTALE and open the debug menu with F3.
