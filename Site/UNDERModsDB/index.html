UNDERTALE SETTINGS+

A quality-of-life settings overhaul for the PC version of UNDERTALE.

* Overview

What It Does

Settings+ upgrades UNDERTALE's basic settings room into a more useful tabbed menu. It also adds SETTINGS and MAIN MENU entries to the in-game C Menu, so you can change options or return to the title without closing the game.

Version: v1 Package: UT_Settings+.zip Tool: UndertaleModTool
DOWNLOAD MOD INSTALL GUIDE

* Included

Highlights

  • Tabbed Settings+ menu with General, Video, Audio, and Controls pages.
  • Fullscreen, window size, language, border, and save-config options.
  • Master, Music, and SFX volume settings.
  • In-game C Menu shortcuts for SETTINGS and MAIN MENU.
  • Optional border image import from the included border image zip.
  • Saves extra settings to UNDERTALE's normal config.ini location.

* Quick Install

Patch Steps

  1. Back up your UNDERTALE data.win.
  2. Extract UT_Settings+.zip.
  3. Open data.win in UndertaleModTool.
  4. Run UT_Settings_Overhaul_v1.csx from UMT's script menu.
  5. Choose whether to import the included border images when prompted.
  6. Save the patched file and launch UNDERTALE.

* Config

Saved Settings

Settings+ writes its options to UNDERTALE's normal local settings file:

C:\Users\YOURNAME\AppData\Local\UNDERTALE\config.ini

Use SAVE CONFIG inside Settings+ after changing options you want to keep.

Patch Steps

  1. Back up your UNDERTALE data.win.

* How to install

INSTALL

  1. Back up your UNDERTALE data.win before changing anything.
  2. Download the mod package you want from the MOD LIST.
  3. Open UNDERTALE's data.win in UndertaleModTool.
  4. Run the mod's included .csx file from UMT's script menu.
  5. If a mod asks about optional assets, follow the prompt and select the included folder or zip contents.
  6. Save the patched copy and keep your clean backup somewhere safe.
  7. Start UNDERTALE and test the mod before adding more patches.

* Settings+ Install

UT_Settings+.zip
