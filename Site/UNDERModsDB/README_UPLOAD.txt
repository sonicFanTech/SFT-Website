SFT UNDERTALE Mods DB
=====================

Upload the full UNDERModsDB folder as-is.

Main changes in this build:
- Home page uses random UNDERTALE background art each time you reload or return to HOME.
- Character sprites keep the same art, but their positions change with the home scene.
- Boot sequence now shows splash 1, then splash 2, then fades into the site automatically.
- The new boot swap sound is included as Assets/Audio/mus_intronoise.ogg.
- The first mod is no longer placed directly on the home page.
- The site now uses same-page hash routes:
  #home
  #mods
  #mod-undertale-debug-menu-port
  #install
  #controls
  #credits
