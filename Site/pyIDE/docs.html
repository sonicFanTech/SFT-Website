Troubleshooting
  • If a script does not run, confirm the selected Python interpreter exists.
  • If external console mode does not open, try Command Prompt or PowerShell before custom terminal entries.
  • If a PyInstaller build fails, check dependencies and script path names.
  • If the AI assistant cannot inspect a project, verify that an active project folder is open and Allow pyIDE Control is enabled.
  • For broader questions, see the Frequently Asked Questions.
