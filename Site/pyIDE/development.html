pyIDE v2.0 - C++ Recode Development

pyIDE v2.0 - C++ Recode Development

The older Python version was useful and functional. The C++ recode is intended to provide a stronger foundation for future development while preserving the useful workflow of the original pyIDE rather than replacing it with a completely unrelated IDE.

  • Improve responsiveness and maintainability.
  • Keep the lightweight Windows-focused editor workflow.
  • Preserve project navigation, run tools, interpreter concepts, and the compiler helper direction.
  • Make room for the built-in AI Desktop Assistant and permission-controlled project tools.
