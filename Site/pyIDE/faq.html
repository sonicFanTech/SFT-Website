Frequently Asked Questions

Straight answers about the legacy release, the C++ recode, and the experimental AI Desktop Assistant.

What is pyIDE?
pyIDE is a lightweight Windows-focused IDE originally designed primarily for Python development.
Is pyIDE v2.0 available yet?
No. pyIDE v2.0 is an in-development C++ recode and no public v2.0 download is listed.
Why is pyIDE being rewritten in C++?
The C++ recode is intended to improve responsiveness, maintainability, and room for future expansion while preserving the useful workflow of the original Python version.
Can I still download the older Python version?
Yes. The legacy Python release remains available through the preserved GitHub release links on the downloads page.
Is pyIDE only for Python?
The original release was primarily designed for Python development. v2.0 may become more expandable, but Python remains the documented legacy focus.
Does pyIDE include a compiler?
The legacy version includes a PyInstaller helper for packaging Python scripts as Windows executables.
What is the AI Desktop Assistant?
An experimental built-in v2.0 assistant intended to help explain code, inspect project context, search project text, and assist with changes through controlled pyIDE tools.
Can the AI assistant access every file on my computer?
No such unrestricted access is claimed. The design is scoped to the active pyIDE project when the user enables permission.
What does Allow pyIDE Control do?
It is the user-controlled option required before assistant project tools should run.
Does the AI assistant require an active project folder?
Project tools are designed to require an active project folder so pyIDE has a clear scope.
Can the AI assistant leave the active project folder?
The tool layer is designed to reject unsafe paths and path traversal attempts such as ../.
Is the AI assistant finished?
No. It is experimental and in active development.
Can AI changes be undone?
Recoverable edit batches and undo support for assistant changes are in development and should not be treated as complete until verified in a public build.
Does pyIDE support local AI models?
Local coding models are part of the current development direction. The setup has been tested with Qwen2.5-Coder 7B, but compatibility details may change.
Is Qwen2.5-Coder 7B required?
Not according to the website documentation. It is listed as a tested local coding model, not as the only supported model.
Where are pyIDE settings saved?
The legacy release uses persistent configuration, including settings such as recent files, themes, autosave, interpreter paths, and console preferences. Exact v2.0 settings paths should be documented when finalized.
Does pyIDE support multiple languages?
The legacy website and downloads include multiple languages. The v2.0 design goal is external JSON-based .langu files.
What Windows versions are supported?
The site does not fabricate exact v2.0 requirements. Final v2.0 system requirements will be published closer to release.
Where can I follow development?
Use the existing GitHub repository: github.com/sonicFanTech/pyIDE.
