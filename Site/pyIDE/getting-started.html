Getting Started

Getting Started with pyIDE

pyIDE is a lightweight Windows-focused IDE originally made for Python development. The current public release is the legacy Python and PySide6 version. pyIDE v2.0 is the in-development C++ recode and should not be treated as downloadable yet.

Current Release Status
  • Use the legacy release if you need a public download today.
  • Read C++ Recode Development to follow v2.0 progress.
  • The AI Desktop Assistant is experimental and requires explicit permission for project-control tools.
Opening and Saving Files
  1. Open pyIDE and use File > Open or Ctrl+O.
  2. Select a Python file or create a new untitled file with Ctrl+N.
  3. Use Ctrl+S to save. Use Ctrl+Shift+S for Save As.
  4. Watch for unsaved indicators in the tab area before closing.
Opening a Project Folder

Open a folder to make it the active project. The project-file manager lets you browse files, open files by double-clicking, create files and folders, rename items, delete items, and open locations in File Explorer where supported.

In the v2.0 AI workflow, the active project folder is also the safety boundary for project tools.

Selecting a Python Interpreter

Use the interpreter manager to select an installed Python interpreter or add a custom python.exe path. Re-discovery can be used when Python installations change. A correct interpreter is required for running scripts and for syntax-checking workflows.

Running a Script Internally
  1. Open or save the Python file you want to test.
  2. Confirm the selected interpreter.
  3. Press F5 or choose the default run command.
  4. Read stdout, stderr, and prompts in the output panel.
  5. If the script asks for stdin, type the input through the internal input support where available.
  6. Use Shift+F5 to stop a running script.
Running in an External Terminal

Use Ctrl+F5 or the external run command to launch a script in a terminal. The legacy workflow includes Command Prompt, Windows PowerShell, PowerShell 7, Windows Terminal when installed, and custom terminal entries.

Autosave and Recent Files

Autosave can save files that already have a real path. Untitled files still need an initial manual save. Settings also include the recent-file list and configurable recent-file limit.
