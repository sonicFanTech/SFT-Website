pyIDE v2.0 is being rebuilt in C++

pyIDE is a lightweight Windows-focused IDE that began as a practical Python development tool. The future v2.0 release is a native C++ recode intended to preserve the useful editor, project, run, settings, and compiler workflows while making the application faster, more polished, and easier to expand.

The new version is not a public download yet. The older Python and PySide6 release remains documented as the legacy stable version while v2.0 is developed.

What is pyIDE?

pyIDE is an independently developed IDE from sonicFanTech, originally built for Python scripting on Windows. It emphasizes normal desktop development tasks: open files, keep tabs, manage a project folder, run scripts, inspect output, choose interpreters, and package simple Python programs.

v2.0 keeps that direction but moves the foundation to C++ so the project can grow into a more responsive and expandable desktop tool.
