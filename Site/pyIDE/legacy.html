pyIDE Legacy - Original Python and PySide6 Version

pyIDE Legacy - Original Python and PySide6 Version

This was the original version before the C++ recode. It remains documented because it is the stable public release while pyIDE v2.0 is being built.

Looking for the future of pyIDE? Read about the v2.0 C++ recode.
Known Legacy Features
  • Lightweight tab-based editor.
  • Multiple open files.
  • Unsaved-file indicators.
  • Line numbers.
  • Find and replace.
  • Dockable project manager.
  • Recent files.
  • Configurable recent-file limit.
  • Autosave.
  • Configurable autosave interval.
  • Dark and light themes.
  • Interpreter manager.
  • Internal script execution.
  • Internal output panel.
  • stdin input support.
  • Script stopping.
  • External console execution.
  • Console selection.
  • Autocomplete.
  • Syntax checking.
  • PyInstaller compiler helper.
  • Settings persistence.
  • Portable configuration behavior where available.
  • Keyboard shortcuts.
Interpreter and Settings Notes

The legacy version includes interpreter discovery, selectable Python interpreters, custom interpreter paths, and persistent settings for themes, autosave, recent files, completion, and external consoles.
