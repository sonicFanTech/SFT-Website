About pyIDE

About pyIDE

pyIDE is an independently developed sonicFanTech project: a lightweight Windows-focused IDE originally created for Python development.

History

The original pyIDE release was built with Python and PySide6. It focused on practical scripting tasks: tabs, file editing, project navigation, interpreter selection, internal and external script execution, settings, themes, and a PyInstaller compiler helper.

Why the C++ Recode Exists

The v2.0 recode is intended to provide a stronger foundation for future development. The goal is not to discard pyIDE's useful workflow, but to rebuild it with better responsiveness, polish, maintainability, and expansion space.

Role of the AI Desktop Assistant

The AI Desktop Assistant is one of the major reasons for expanding the architecture. It is being designed to work through permission-controlled pyIDE tools so project context can be inspected deliberately, with user control and active-project boundaries.
