VPK Browser

About this tool

The VPK Browser lets you browse Valve VPK packages like a virtual file system and extract resources without opening the complete SERV package around it.

A common workflow is to extract a VMT or VTF from a VPK and then inspect it in the corresponding standalone viewer.

Why a separate page? This tool has its own download slot so users can get it without downloading the complete SERV installer or portable archive.
Features
  • Open .vpk files
  • Support _dir.vpk archive sets
  • Folder/file tree
  • File metadata where available
  • Search and filtering
  • Extract selected files
  • Extract visible/filtered files
  • Locate materials, textures, models, scripts, sounds and maps
