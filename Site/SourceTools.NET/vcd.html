How this category is organized

The vcd.html page is the directory/list for the file type. Individual tool documentation lives inside the VCD/ sub-folder so new tools can be added later without turning the upper-level directory into a flat list of dozens of pages.

Standalone downloads: each tool page has its own installer/portable download area. Unpublished packages are shown as disabled buttons until a real build is ready.
