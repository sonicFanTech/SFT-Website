About Source Tools

Source Tools is an umbrella site for independent Source Engine research, inspection, map and utility programs.

Why the site is split by file type

The site uses one small HTML directory page per file type and keeps each tool in a matching sub-folder. That means a future second VTF, VPK or BSP utility can be added beside the first one without redesigning the site.

SERV download model

SERV remains a complete suite distribution, but Source Tools also acts as the individual-tool download center. A standalone package can eventually contain only the selected utility and the runtime files it actually requires.

Until those packages are published, individual download buttons are deliberately greyed out rather than pointing to nonexistent files.
