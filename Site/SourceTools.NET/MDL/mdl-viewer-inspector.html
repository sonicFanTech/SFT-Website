About this tool

The MDL Viewer / Inspector handles Source model files and their associated VVD, VTX and PHY resources.

Experimental areas include full mesh assembly, VTX strip handling, texture resolving, VMT/VTF loading and accurate rendering across every Source branch.

Why a separate page? This tool has its own download slot so users can get it without downloading the complete SERV installer or portable archive.
Features
  • Open .mdl files
  • MDL header information
  • Companion file detection
  • Model name/version/checksum
  • Bone/texture/body-part/hitbox/sequence counts
  • OpenGL preview panel
  • Attempt real mesh loading from VVD/VTX
  • Bounds/cube fallback preview
  • Texture/material browser
  • Model summary export
