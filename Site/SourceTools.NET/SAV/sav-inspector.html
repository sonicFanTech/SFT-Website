About this tool

The SAV Inspector handles save files and general binaries when a complete game-specific decoder is not available.

Different Source games can use very different save formats, so this tool intentionally emphasizes inspection rather than universal decoding.

Why a separate page? This tool has its own download slot so users can get it without downloading the complete SERV installer or portable archive.
Features
  • Open .sav/.dat/.bin and unknown binary files
  • File/header metadata
  • Save-like header detection where possible
  • ASCII string extraction
  • Probable embedded path/reference detection
  • Reference type guesses
  • Hex preview
  • String search/filtering
  • Summary export
