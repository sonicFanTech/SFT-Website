About this tool

The PCF Inspector focuses on practical inspection of Source particle files, especially readable names and references in binary PCF data.

Full PCF/DMX-style parsing is a later goal; the current concept emphasizes useful early inspection.

Why a separate page? This tool has its own download slot so users can get it without downloading the complete SERV installer or portable archive.
Features
  • Open .pcf files
  • Readable string extraction
  • Particle-system name hints
  • Operator hints
  • Renderer hints
  • Material/texture-related strings
  • String offsets
  • Type hints
  • Search/filtering
  • PCF summary export
