About this tool

The DEMO Player / Inspector reads Source demo files and can construct a launch command for Source demo playback in a selected game.

Playback depends on the game and Source branch. A typical launch style is -game "portal2" -console -novid +playdemo "demo".

Why a separate page? This tool has its own download slot so users can get it without downloading the complete SERV installer or portable archive.

  • Hex preview
  • Summary export

  • Extra launch arguments

  • Clipboard copy
  • Demo launch
