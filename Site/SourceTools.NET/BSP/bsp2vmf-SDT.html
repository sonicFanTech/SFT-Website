About this tool

bsp2vmf-SDT is the standalone Source Decompiler Tool. It is intended to take a compiled BSP and reconstruct an editable Hammer VMF representation.

The current project line is still in development. Generated geometry accuracy and complete wall/brush reconstruction are still being worked on.

Why a separate page? This tool has its own download slot so users can get it without downloading the complete SERV installer or portable archive.
Features
  • Open compiled BSP maps
  • Analyze BSP map information needed for decompilation
  • Generate editable VMF output
  • Separate decompiler tool from SBSPE
  • Designed for future expansion of BSP-to-VMF reconstruction
