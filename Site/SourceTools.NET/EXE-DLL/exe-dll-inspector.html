About this tool

The EXE/DLL Inspector is a legacy SERV utility slot for inspecting Windows executables and libraries, including embedded resources and metadata.

The current SERV documentation lists the EXE/DLL Inspector among the tools not yet remade in C++. This Source Tools page is kept ready for a future standalone build.

Why a separate page? This tool has its own download slot so users can get it without downloading the complete SERV installer or portable archive.
Features
  • Binary metadata inspection
  • Embedded resource inspection
  • Icons and resource data
  • String/resource-oriented inspection
