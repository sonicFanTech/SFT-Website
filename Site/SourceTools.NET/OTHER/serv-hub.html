About this tool

SERV Hub is the main launcher and management application for the Source Engine Resources Viewer suite.

The Hub is intentionally not tied to one Source file type. It organizes the standalone viewers, inspectors and utilities in one suite.

Why a separate page? This tool has its own download slot so users can get it without downloading the complete SERV installer or portable archive.
Features
  • Native C++ / Qt interface
  • Tool categories
  • tool.servtool.json metadata
  • Tool status checking
  • Missing dependency warnings
  • Search/filtering
  • Open tool folder
  • Launch selected tool
  • About/legal sections
  • Hidden/internal tool support
  • Broken-tool detection
