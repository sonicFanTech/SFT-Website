About this tool

The SND Inspector covers Source sound-script inspection and basic metadata extraction from selected audio files.

This makes the SND tool useful for tracing sound script entries and the audio resources they refer to.

Why a separate page? This tool has its own download slot so users can get it without downloading the complete SERV installer or portable archive.
Features
  • Open Source sound scripts
  • Parse sound entries
  • Channel information
  • Sound level
  • Volume
  • Pitch
  • Wave references
  • WAV RIFF/WAVE metadata
  • Basic MP3/ID3 detection
  • Readable-string extraction
  • Raw text search
  • Sound summary export
