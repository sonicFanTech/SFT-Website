Basic usage:

Open and inspect a game

Start SplitGM through SGMVMDLauncher.exe.

Select File → Open game...

Choose a supported GameMaker data file or executable.

Wait for loading and profile detection to finish.

Browse resources through the Resource Explorer.

Open code entries to inspect reconstructed GML or VM assembly.

Use relationship tools to navigate connected resources and code.

Use the Export menu to recover selected resources or complete categories.

Run the loaded game from TEMP

Load a supported Windows GameMaker game.

Select Tools → Run Game from TEMP.

Confirm or select the original runner executable when requested.

Wait for TEMP preparation and launch.

Review the Activity Log or TEMP-run log when needed.

Use Tools → Open Current TEMP Run Folder to inspect the run manifest.

Export an organized SplitGM extraction project

Use the extraction-project export when the goal is to inspect code, metadata, indexes, assets, relationships, and errors outside GameMaker.

This is separate from the reconstructed .yyp feature.

Decompile to a reconstructed GameMaker project

Open Tools → Settings → Experimental.

Enable Decompile to .yyp Project.

Load a supported GameMaker VM game.

Select Tools → Decompile to Reconstructed .yyp Project...

Choose a parent output directory.

Review queued resources and progress.

Read the reconstruction, validation, and repair reports.

Open the generated .yyp in a compatible GameMaker IDE.

Treat GameMaker's own parser/compiler output as the final authority.

Do not overwrite an unrelated project directory.
