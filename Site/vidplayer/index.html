What the C# Suite Includes

▶
VidPlayer

Portable LibVLC audio playback, playlists, artwork, subtitles, visualizers, themes, localization, Discord Rich Presence, and Audio CD support.

↻
C# Updater

External update channels, package verification, protected portable data, rollback snapshots, restore, and relaunch support.

🎨
VPTheme Tools

A rebuilt C# theme editor plus a protected mock VidPlayer environment for test-running unsaved themes.

💿
VPACDRipper

A WPF Audio CD ripper using BASSCD/BASSenc for WAV, FLAC, and MP3 output.

Major Rebuild Improvements

  • Real LibVLC PCM visualizer data with safe signed-16-bit native sample handling.
  • Standalone and docked playlists with left, right, top, bottom, and visualizer-tab docking.
  • Remembered window size, position, scaling, maximized state, and docking state.
  • Application-wide WPF theming, including dark menus and context menus.
  • Built-in Discord Application ID with automatic reconnect attempts.
  • Visible VidPlayer-authored component DLLs while framework and third-party managed dependencies stay bundled.
  • Complete C# replacements for the updater, VPTheme Editor, and VPACDRipper.
