Theme Engine & VPTheme Editor

🖌️
Theme Styling Support

VidPlayer theme support now covers main window colors, dialogs, menu bars, text fields, tabs, playlists, tooltips, sliders, progress bars, and more.

📁
Theme Asset Loading

Custom themes can now use self-contained folders for Sounds, Icons, and Fonts, plus built-in Default/... asset paths.

🔤
Font Fallback Handling

If a custom theme font is missing, VidPlayer now falls back to the default font so the theme can still load and be used.

🔊
UI Sound Support

The theme engine now supports UI sounds, hover sounds, playback control sounds, dialog sounds, tab sounds, menu sounds, and sound volume settings.

VidPlayer — C++ Port

The C++ port is the new native rewrite of VidPlayer. The idea is to keep the same overall soul while moving the project toward a compiled build with quicker startup, lower runtime dependency weight, and a cleaner long-term base for future expansion.
