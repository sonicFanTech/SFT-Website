Install VidPlayer C# Rebuild

  1. Download the complete build ZIP.
  2. Extract all files to a writable folder such as C:\Apps\VidPlayer-CS.
  3. Keep every portable folder beside VidPlayer.exe.
  4. Launch VidPlayer.exe.
Download Build

Use the Player

  • Open audio with File → Open Files, drag-and-drop, or command-line paths.
  • Open the playlist from View → Playlist.
  • Enable docked playlist mode in Settings and choose a docking area.
  • Use File → Play Audio CD for CDDA playback.
  • Use Tools → Open CD Ripping Tool for WAV, FLAC, or MP3 ripping.
  • Use Tools → VPTheme Editor to create or modify themes.

Theme Testing

  1. Open or create a theme in VPTheme Editor.
  2. Edit colors, fonts, icons, sounds, gradients, and dimensions.
  3. Choose Test Run Theme.
  4. Inspect the mock main window and subwindows.
  5. Keep the editor open; unsaved edits continue updating in the tester.

Build from Source

Download the C# source package, place the complete runtime-assets folder beside Build-Release.cmd, and run the build script. The repository README contains the complete source layout and requirements.
