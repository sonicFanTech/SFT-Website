VidPlayer v2.0.9.2 — CS V1.0 Features

This is the website feature reference for the completed C# / WPF rebuild. It describes the finished product—not internal repair or test-build history.

Download BuildSource Repository

Product Suite

  • VidPlayer.exe — main portable player
  • VidPlayerUpdater.exe — C# update and rollback manager
  • VPTheme.Editor.exe — C# theme editor
  • VPTheme_ThemeEnvironmentTester.exe — protected UI testing environment
  • VPACDRipper.exe — C# WPF Audio CD ripper powered by BASSCD

Playback

  • Portable LibVLC/LibVLCSharp playback
  • AAC, FLAC, M4A, MP3, OGG, WAV and WMA opening
  • Play, pause/resume, stop, previous, next and seek
  • Autoplay next and optional session restoration
  • Normal volume plus optional VLC boost
  • Audio CD CDDA playlist playback
  • Command-line opening and drag-and-drop

Playlists

  • Standalone and docked playlist modes
  • Left, right, top, bottom and visualizer-tab docking
  • Add, remove, reorder, search, save, load, unload and clear
  • Drag-and-drop and drag-to-reorder
  • Bulk loading progress with counts and cancellation
  • Audio CD playlist population and current-track synchronization

Artwork, Metadata and Lyrics

  • Embedded and external artwork
  • Portable artwork mappings and VPLogo fallback
  • Full Screen Artwork and Mini Mode
  • Multi-file File Info
  • TagLibSharp metadata and ffprobe technical details
  • LRC, SRT, WebVTT, ASS and SSA support
  • Subtitle color, font, position, background and timing controls

Visualizer

  • Bars, waveform, XP WMP-style blobs and spectrogram
  • Main, full-screen and mini visualizer windows
  • Built-in/custom color presets
  • FFT, Hann windowing, logarithmic bands and smoothing
  • Real LibVLC signed-16-bit PCM callback analysis
  • Position-synchronized FFmpeg analysis and fallback
  • Visible/logged PCM activation and safe analyzer lifecycle

Themes and Localization

  • Light, Dark, System Default and SteamLike choices
  • Custom .vptheme files
  • WPF windows, dialogs, menus, context menus, buttons, inputs, tabs, playlists, sliders, progress bars and tooltips
  • Gradient styling where supported
  • Custom fonts, icons, app logo and UI sounds
  • Self-contained theme assets with fallback behavior
  • JSON-based .langu localization and localized docs

Window and Session Behavior

  • Remember size, position and maximized state
  • Optional placement restoration
  • Off-screen correction
  • 75%–150% UI scaling
  • Scale-aware minimum sizing
  • Remembered playlist docking
  • Normal-window restoration after Mini Mode

Updater and Rollbacks

  • Separate C# WPF updater
  • Release, pre-release, beta, experimental and all-build channels
  • Automatic/manual checks and optional silent operation
  • SHA-256 verification when provided
  • Path containment and traversal protection
  • Preservation of editable user files
  • Manifest-based rollback snapshots and restore/delete controls

VPTheme Editor

  • New/Open/Save/Save As/Duplicate workflow
  • Unsaved-change prompts
  • Theme search and folder discovery
  • Roughly 170 schema-driven properties
  • Interactive Main, Settings, Playlist and About previews
  • Asset packaging into Theme.vptheme, Sounds, Icons and Fonts
  • Test Run Theme with live unsaved updates

Theme Environment Tester

  • Mock VidPlayer main window and subwindows
  • Playlist, Settings, File Info, About, Mini Mode and visualizer previews
  • Loads filenames without audio playback
  • Does not initialize LibVLC
  • Protected editor-authenticated launch and automatic shutdown

VPACDRipper

  • C# WPF replacement for the old Win32 UI
  • BASS/BASSCD/BASSenc engine retained
  • Optical-drive and track detection
  • CD-Text metadata and editable track fields
  • WAV PCM, FLAC and MP3 output
  • Rip Selected, Rip All, progress and cancellation
  • Safe cleanup of incomplete output
  • Portable INI settings and Ripped CDA integration

Compatibility and Packaging

  • Existing portable JSON settings and data files remain supported where applicable
  • Existing .vpl playlists, .vptheme themes and .langu language files remain supported
  • Visible VidPlayer-authored DLLs beside the main EXE
  • System, Microsoft, .NET runtime and managed third-party dependencies bundled
  • Native VLC, FFmpeg, BASS, themes, icons, sounds and editable data remain external
