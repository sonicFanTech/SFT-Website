What Is Inside the C# Build?

  • VidPlayer.exe and its visible VidPlayer component DLLs.
  • VidPlayerUpdater.exe with update and rollback support.
  • VPTheme.Editor.exe and VPTheme_ThemeEnvironmentTester.exe.
  • VPACDRipper.exe with the required native BASS libraries.
  • Portable VLC, plugins, FFmpeg, ffprobe, themes, languages, icons, sounds, and editable settings.

Installation

  1. Download the complete C# build ZIP.
  2. Extract the entire archive to a normal writable folder.
  3. Do not run the application from inside the ZIP.
  4. Keep the complete bin, update, theme, language, VLC, and helper-tool folders beside VidPlayer.exe.
  5. Launch VidPlayer.exe.

The precompiled C# build is self-contained and does not require a separate .NET runtime installation.
