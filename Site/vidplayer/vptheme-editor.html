VPTheme Editor — C# / WPF Rebuild

The standalone theme editor is now part of the VidPlayer C# Rebuild suite. It replaces the older Python editor and works directly with the rebuilt WPF theme system.

Download VidPlayer CS SuiteDownload SourceTheme Packs

Editor Features

  • New, Open, Save, Save As, and Duplicate.
  • Unsaved-change prompts and safe theme switching.
  • Automatic VidPlayer VPThemes-folder discovery.
  • Theme search, refresh, and starter themes.
  • Schema-driven editing of roughly 170 properties.
  • Main Window, Settings, Playlist, and About previews.
  • Color, gradient, number, boolean, font, icon, sound, and asset editors.
  • Self-contained theme packaging with Theme.vptheme, Sounds, Icons, and Fonts.

Test Run Theme

The editor can launch VPTheme_ThemeEnvironmentTester.exe with the current theme, including unsaved edits. Changes continue to update in the tester while the editor remains open.

  • Mock main player window.
  • Standalone and docked playlist previews.
  • Settings, File Info, About, Mini Mode, Full Screen Artwork, Full Screen Visualizer, and Mini Visualizer previews.
  • Mock media-file and playlist loading without LibVLC or audio output.
  • Protected launch requiring a valid active editor session.

Theme Folder Layout

bin\VPThemes\ThemeName├─ Theme.vptheme
├─ Sounds├─ Icons└─ Fonts\

Built-in assets can use Default/... paths, while custom themes can use paths relative to their own theme folder.
