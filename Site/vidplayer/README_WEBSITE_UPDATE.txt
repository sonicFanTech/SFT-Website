VIDPLAYER WEBSITE — C# REBUILD UPDATE
=====================================

This package updates the complete VidPlayer website for VidPlayer v2.0.9.2 — CS V1.0.

Main changes:
- C# / WPF / .NET 10 rebuild is now the recommended current edition.
- All former C++ port/rebuild promotion has been removed or replaced.
- Direct C# build, source, repository, release, and issue links are used.
- New complete Features page covers the player, updater, VPTheme Editor,
  Theme Environment Tester, and VPACDRipper.
- Downloads, Home, About, FAQ, Manuals, Changelogs, Contact, Archive,
  VPTheme Editor, Theme Packs, Screenshots, License, and Thanks pages updated.
- Python edition is preserved as the original separate codebase.
