Cloudflare Access — Admin Setup Guide

// HOW TO PROTECT YOUR ADMIN PANEL WITH A ONE-TIME EMAIL CODE — STEP BY STEP

What this does: Cloudflare Access sits in front of your admin page at the network level. When anyone visits yoursite.com/admin-vp9x2k.html, Cloudflare intercepts them before the page loads and demands authentication. You configured it to only allow your specific email address — so Cloudflare sends a one-time code to that email, you enter it, and you're in. Anyone else gets blocked entirely. No password to remember. No way for another Cloudflare user to get in.
Cost: Cloudflare Zero Trust has a free tier that covers up to 50 users. This entire setup costs nothing. FREE
Prerequisite: Your site domain must already be on Cloudflare (proxied through their nameservers). If you're hosting on GitHub Pages with a custom domain through Cloudflare, you're already set.
1 Enable Cloudflare Zero Trust

Log into your Cloudflare dashboard at dash.cloudflare.com.

In the left sidebar, look for Zero Trust. Click it.

Cloudflare Dashboard › Zero Trust

If this is your first time, it will ask you to create a Zero Trust organisation. Enter any team name you want — it doesn't matter, it's just an internal label. Something like vidplayer works fine.

When asked to choose a plan, select the Free plan. You don't need to enter payment info.

2 Create an Access Application

Inside Zero Trust, navigate to:

Zero Trust › Access › Applications

Click "Add an application", then choose "Self-hosted".

Fill in the Application fields

Application name
Anything you like — e.g. VidPlayer Admin Panel
Session Duration
24 hours — so you don't need to re-authenticate every visit
Application domain
Your site domain, e.g. sonicfntech.org
Do NOT include https:// — just the domain
Path
admin-vp9x2k.html
This tells Cloudflare to only protect that specific file, not the whole site
The full protected URL will be: yoursite.com/admin-vp9x2k.html
Every other page on your site remains publicly accessible as normal.

Leave all other settings as defaults. Click Next.

3 Create the Access Policy (Allow Only Your Email)

This is the step that makes it yours-only. You're now on the Policies screen.

Click "Add a policy" and fill it in like this:

Policy name
Owner only
Action
Allow

Include rule (WHO can get in)

Selector
Emails
Value
sonicfantech@sonicfntech.org
This is the ONLY email that will receive the login code. Put your real email here.
Why only your email? Cloudflare Access sends a one-time code to whatever email tries to log in, but only processes it if the email matches this list. So even if someone else tries their own email, they'll get "Access Denied" — the code only works for the exact address you typed here.

Click Save policy, then Next, then Add application.

4 Set Up the Login Method (One-Time PIN via Email)

Navigate to:

Zero Trust › Settings › Authentication

Under "Login methods", make sure One-time PIN is enabled (it usually is by default on new Zero Trust accounts). This is what sends a 6-digit code to your email when you try to log in.

You don't need to add any third-party identity providers (Google, GitHub, etc.) — the one-time PIN is enough.

5 Test It

Open a private/incognito browser window and go to:

https://yoursite.com/admin-vp9x2k.html

You should see a Cloudflare Access login page — not your admin panel. Enter your email address. You'll receive a 6-digit code by email within seconds. Enter the code and you'll be taken straight to the admin panel.

What visitors see if they try to access it

Anyone who visits the URL and enters an email that isn't on your list gets a Cloudflare "Access Denied" page — they never see the admin panel HTML at all. It's blocked at Cloudflare's edge before the request even reaches GitHub Pages.

Important: Cloudflare Access only works when traffic is proxied through Cloudflare (the orange cloud icon is ON for your domain in the DNS settings). If you ever pause Cloudflare proxying, the admin page would be unprotected.
6 (Optional) Rename the Admin File for Extra Obscurity

The admin file is currently named admin-vp9x2k.html — already not guessable. But if you want to rename it to something even more obscure, like ctrl-9f2a.html, you can. Just update the path in Cloudflare Access to match the new filename.

With Cloudflare Access protecting it, the filename barely matters — but defence in depth never hurts.
