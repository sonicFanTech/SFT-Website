About VidPlayer

VidPlayer is a portable Windows audio-player project created by sonic Fan Tech / sonic Fan Games. It grew from a small player into a full suite covering playback, playlists, artwork, metadata, visualizers, subtitles, themes, localization, updating, rollback management, and Audio CD tools.

The C# Rebuild

The former native rewrite plan was replaced by the completed C# / WPF / .NET 10 rebuild. This approach keeps the desktop application native to the modern Windows .NET stack while preserving VidPlayer's portable folder layout and editable data files.

  • Main player rebuilt in C# and WPF.
  • Updater rebuilt in C# and WPF.
  • VPTheme Editor rebuilt in C# and WPF.
  • Theme Environment Tester added for protected full-UI theme testing.
  • VPACDRipper rebuilt in C# and WPF while retaining BASSCD.

Separate Repositories

The original Python edition and the C# rebuild are intentionally separate. This avoids mixing incompatible project files, dependencies, build instructions, issues, and releases.
