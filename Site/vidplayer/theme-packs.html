How These Downloads Work

These downloads are not just raw theme folders. Each official theme pack download is planned to be an installer program so users can install the theme more easily if they do not want to set it up manually.

Manual Theme Folder Reminder

VidPlayer themes normally use self-contained theme folders such as:

VPThemes\ThemeName\Theme.vptheme
VPThemes\ThemeName\Sounds\
VPThemes\ThemeName\Icons\
VPThemes\ThemeName\Fonts\

The official theme pack installers are meant to automate that setup for users.
