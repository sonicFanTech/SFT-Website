GitHub Issues

The best way to report bugs if you have a GitHub account:

  • Open an issue on the VidPlayer repo

Please include your Windows version, VidPlayer version, and what you did right before it broke.

Before Sending a Bug...

  • Check you're on the latest version — see Downloads.
  • Try a different audio file to see if it's file-specific.
  • Note any error messages or weird behavior.
  • Include your Windows version and VidPlayer version.
