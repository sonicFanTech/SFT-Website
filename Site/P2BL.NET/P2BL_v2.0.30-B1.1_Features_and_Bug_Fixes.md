## About this release

R-2 BETA 1.1 is a tested update to Portal 2 BETA Launcher, the Windows research utility for working with historical Portal 2 beta builds. This release brings the download and build-identification workflow together with the launcher, refreshed fix installation, first-party tool discovery, and the custom in-game overlay.

## Features

- Discover and manage local Portal 2 beta builds.
- Launch supported builds using build-specific executable and launch handling.
- Check the hosted-download database for direct archives, falling back to available backup/Gofile links.
- Cancel active downloads and manage archive files through the launcher.
- Identify and verify builds using SHA-256 records from the remote BHT database.
- Install supported No-Steam fixes while backing up files before replacement.
- Use 7-Zip for supported `.zip` and `.7z` archive operations.
- Browse and launch detected first-party tools from the Extra Tools page.
- Use the custom in-game overlay with movable/resizable sub-windows.
- Capture screenshots and manage them through Screenshot Manager.
- Preview screenshots inside the overlay.

## In-game controls

- `Shift + Z` — Toggle the overlay.
- `Shift + 9` — Capture a screenshot.
- `Escape` — Hide the overlay while it is open.

## Notes

Build identification uses the available hash database. An installation may remain unknown if its hashes are not represented. Archive support may be limited if the required extraction components are missing.
