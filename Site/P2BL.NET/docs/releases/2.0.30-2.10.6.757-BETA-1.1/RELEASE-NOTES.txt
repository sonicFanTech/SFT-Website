OVERVIEW
P2BL is a Windows launcher and research utility for organizing, launching, and exploring historical Portal 2 beta builds. BETA 1.1 builds on the R-2 interface and brings together build management, hosted downloads, hash-based build identification, fix installation, first-party tools, and the in-game overlay.

HIGHLIGHTS
- Build Manager and build discovery workflow for local Portal 2 beta installations.
- Build-specific launch handling and launch options.
- Download button workflow that checks the hosted download list first and uses available backup/Gofile links when appropriate.
- SHA-256 identification and verification using the remote BHT data file.
- Download cancellation and managed archive handling.
- Updated No-Steam fix installation with backups of files that are replaced.
- 7-Zip integration for supported archive formats.
- Extra Tools page for detected first-party utilities.
- Custom in-game overlay with movable/resizable sub-windows.
- Screenshot Manager, screenshot capture, and screenshot preview.

IN-GAME CONTROLS
Shift + Z  — Toggle the in-game overlay.
Shift + 9  — Capture a screenshot.
Escape      — Hide the overlay while it is open.

IMPORTANT
This is a Beta release. Build identification depends on available hash records; unsupported or unmatched installations may still be reported as unknown. Archive compatibility depends on the archive type and available extraction components.
