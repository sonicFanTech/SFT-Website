============================================================
1. CORE PURPOSE
============================================================

[WORKING]
- Dedicated launcher/management application for Portal 2 BETA builds.
- Intended for Portal Series BETA Research (PSBR) use and related research/testing.
- Designed to make launching, organizing, and working with multiple Portal 2 beta builds easier.
- Supports the idea of keeping several different beta builds available in one launcher instead of handling each build manually.
- Built as a Windows desktop application in C#.

[IN DEV]
- R-2 is the major redesign of the original R-1 prototype.
- R-2 is intended to replace the basic/prototype UI with a significantly more complete launcher experience.

3. BUILD DISCOVERY / SCANNING
============================================================

[IN DEV]

- Scan user-added folders for Portal 2 beta builds.

- Persistent storage of previously discovered build/install locations.
- Ability to reuse known build paths without requiring a complete rescan every time.
- Smarter handling of already-known installations.

[UNCERTAIN]
- Additional scan optimization/error handling beyond the current fast-scanning approach.
