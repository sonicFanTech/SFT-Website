GODMODEDELTARUNE v2

Chapters 1-5 • Runtime Controls

SFT DELTARUNE God Mode v2 keeps party HP protected while giving you full control over when protection is active. God Mode, grazing, the on-screen overlay, hit effects, colors, and timeout behavior can all be changed while the game is running.

What changed in v2

Version 1 permanently replaced several damage functions. Version 2 preserves the original chapter damage code and only bypasses it while God Mode is enabled. This makes the F9 OFF state return the game to normal damage behavior instead of leaving permanent protection active.

Installation Guide

Install the script separately into each chapter you want to use it with.

Install with UndertaleModTool

  1. Make a backup of the original chapter data file and your DELTARUNE save files.
  2. Open a clean Chapter 1, 2, 3, 4, or 5 data file in UndertaleModTool.
  3. Open the Scripts menu and choose Run other script....
  4. Select DR_GODEMODE_v2.csx.
  5. Wait for the script to finish and review its patch report.
  6. Save the modified data file from UndertaleModTool.
  7. Launch that chapter and press F8 to open the config menu.
  8. Repeat these steps for every other chapter you want patched.

Required clean-file rule

Do not install v2 over God Mode v1. Version 1 permanently replaced original damage functions, so v2 cannot recover them. Restore the original data file or a clean pre-v1 backup before installing.

The installer also stops if it finds an existing obj_sft_godmode_controller, which helps prevent accidental double installation.

How the Toggles Behave

God Mode ONParty HP and detected special-mode life values are restored or protected. Death processing is blocked.
God Mode OFFThe original chapter damage code runs normally again, and forced special-mode invincibility flags are cleared.
Damage Effects OFFDamage routines are bypassed early where supported, reducing hit flashes and repeated damage feedback.
Damage Effects ONThe game may show normal hit feedback, but the controller restores protected HP while God Mode remains enabled.
Grazing BLOCKEDDetected graze-box and bullet collision events exit before their normal TP-gain logic runs.

Important Notes

  • Use clean chapter data files and keep backups.
  • The mod changes game code and is unofficial.
  • Chapter updates may change object or script names and require a future mod update.
  • Unusual room transitions or third-party mods may conflict with the persistent controller.
  • Test one chapter first before patching all five.
