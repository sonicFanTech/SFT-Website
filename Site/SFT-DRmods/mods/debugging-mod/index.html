Install Guide

Steps

  1. Back up the chapter’s original data file first.
  2. Open the chapter data file in UndertaleModTool.
  3. Go to Scripts / Run other script... and select DELTARUNE_Debug_Menu_v1.csx.
  4. Save the patched data file.
  5. Launch the game and press F3 to open/close the debug menu.

Controls

F3 = open / close menu Up / Down = move selection Enter = select / toggle Backspace / Esc = go back Controller builds: Back+Start open/close, A select, B back

Some behavior can vary per chapter because each chapter has its own object/script/resource layout.
