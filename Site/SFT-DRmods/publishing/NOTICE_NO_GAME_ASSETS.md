# No DELTARUNE Game Assets Included

This package intentionally does not include exported DELTARUNE GML code, sprites, music, sound effects, data files, save files, or other game assets.

The folders under `SFT_DDM_GML_Source/` are placeholders only. Users who want GML Code Viewer previews must export code from their own copy of DELTARUNE using UndertaleModTool and place the exported files into the matching chapter folder before running the `.csx` installer.

Do not redistribute a package containing Toby Fox / DELTARUNE game code or assets.
