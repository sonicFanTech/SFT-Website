# SFT DELTARUNE Debug Menu v2

## Short description

Unofficial fan-made UndertaleModTool debug/research menu for DELTARUNE Chapters 1–5.

## Page description

SFT DELTARUNE Debug Menu v2 is a `.csx` mod for UndertaleModTool that adds an in-game debugging menu to DELTARUNE. It is built for modders, researchers, and unused-content hunting.

This is not a normal gameplay mod. It is a tool for inspecting and testing the game.

## Features

- Room Select with search.
- No-clip and movement tools.
- Visual and collision overlays.
- Sound Test.
- Sprite / Animation Viewer.
- Runtime Info.
- Object Browser.
- GML Code Viewer with optional local exported-code previews.
- Flag / Global Viewer with optional metadata.
- Runtime Logger with side overlay.
- Save Tools safety page.
- Script Call.
- Object Spawner.
- Mouse / click inspector.
- Controller support.
- Persistent debug menu settings.

## Install instructions

1. Back up your DELTARUNE data file and saves.
2. Open the target chapter `data.win` in UndertaleModTool.
3. Run `DR_DDM_v2.csx` from the package.
4. Save the patched data file.
5. Launch the game and press `F3`.

## Controls

```text
F3 = open / close menu
Up / Down = move
Left / Right = change values
Enter = select
Esc / Backspace = back
Back + Start = controller open / close
A = controller select
B = controller back
```

## Warning

This is a debugging tool. It can break the game state if used wrong.

Back up your saves and use test data files. Object Spawner and Script Call are dangerous advanced tools.
